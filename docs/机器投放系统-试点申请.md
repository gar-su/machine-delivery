## 一、一句话价值
新剧上线后由系统按语种自动绑定进 Meta / TikTok 测新任务，新剧从上线到开投的周期由 __ 天缩短至 __ 天，单批测新的人工投入由 __ 人天降至「一次勾选确认」。已投出效果的剧由上游决策系统判定后进入「跟投信号」页，一次批量确认即可放量。两条路径**确认之前都不会投出去**。本组自行承担投放效果，数据全部对账公开。

## 二、最小方案（一句话即可批复）
> 「批一个季度试点：预算上限 __，账户走白名单，亏到 __ 就停，效果数据对账公开。」

| 项 | 内容 |
|---|---|
| 试点范围 | 新剧测新（批量测新）+ 跟投，两条路径均接入 |
| 试点周期 | 一个季度（__ 至 __），到期按数据决定扩权或收口 |
| 预算 | 独立预算池，上限 __；不占用现有优化师团队预算 |
| 账户 | 白名单 __ 个账户，账户主体 __ |
| 止损线 | 累计亏损达 __ 即熔断停投；恢复需重新审批 |
| 考核口径 | 一期的建设成果与试点投放效果分开计，试点亏损不倒扣一期 |
| 执行方式 | 两条路径均为「系统按配置自动绑定 + 人工批量确认」：测新在测新清单勾选短剧确认，跟投在「跟投信号」页勾选信号确认。排期东八区 |

前置条件一：账户授权与权限修复是本试点开工的前提，未落地则无法验证（规划期盘点中，FB OAuth 权限问题曾致 91.2% 投放失败）。

前置条件二：跟投依赖上游 smart_ad_put 闭环三项——素材级决策能力、语种取值对齐（上游语言名 ↔ 本系统语种）、本系统信号接收端形态。上游信号已产出并落盘，契约以其实际字段为准，不需要它另做改动。上述未闭环则不开投：信号要么送不到，要么解析不出投到哪。
跟投与测新一样，**确认之前不产生任何消耗**，人工确认就是它的投放闸门；止损线按此口径设定即可，不必额外加固。

- 跟投信号可在「跟投信号」页逐条查看（含上游判定原因、置信度与状态），不需要额外的人工巡检
- 未配置语种、绑定跳过、数据异常在执行记录中可查，不需要额外的人工巡检
