# 机器投放系统 · 用户手册
> 面向运营 / 优化师 · 配套后台原型 v1.8 · 覆盖本期已上线功能
## 1. 这个工具帮你做什么
新剧上线后，过去要人工决定投哪部剧、配多少预算、开哪些账户、什么时候投。这套系统接管了其中两环：新剧由信号自动提醒进入测新清单，你勾选后，系统按各短剧语种把短剧绑定进 Meta 与 TikTok 的测新默认自动化任务并投放。预算、账户、竞价等执行参数由自动化任务承载，你不需要逐项填写。
你在后台的日常有四件事：
- **发起测新**——从测新清单勾选短剧，批量发起，确认配置与排期
- **确认跟投**——从「跟投信号」页勾选信号，批量确认（确认后系统才投）
- **查执行记录**——看哪条信号绑了什么任务、绑成没有、任务在不在跑
- **维护默认自动化任务**——确保要投的语种都绑好了 Meta 与 TikTok 任务
> 跟投本期已接入：上游决策系统判定某目标值得放量后，信号进入「跟投信号」页**待确认**；你勾选信号批量确认后，系统才按「目标维度 × 语种」绑定进 Meta / TikTok 跟投任务。跟投和测新一样，**确认之前不会投出去**。

## 3. 测新清单（你的主要工作）
### 3.1 清单从哪来
短剧上线或预上线后，系统会发一条上线信号。这条信号**只提醒、不自动投放**——它把新剧放进测新清单，并在「上线状态」列打上 `新上线` 标记。测新由你从清单勾选后发起。
清单展示**全部**短剧，不只是新上线的。不带 `新上线` 的都是 `已上线`，表示此前已在库中，未被发起过测新。
> 短剧信息分三列展示：剧本编号（如 `LA001`）、剧本名、短剧名。业务上剧本与短剧是两级——一个剧本下可以有多个短剧，所以编号与名称分开列。剧本名只作展示，不参与筛选。
### 3.2 找到要测的短剧
顶部筛选支持五种方式，可组合使用：
- **语言**——中文 / 英语 / 韩语 / 泰语 / 马来语
- **短剧名**——按短剧名筛选，例如输入「霸总」命中 `LA001 霸总的替嫁新娘`
- **剧本编号**——按剧本编号筛选，例如输入 `LA001`
- **上线时间**——选起止日期，筛出这段时间内上线的短剧，含首尾两天；只填一端就是「该日期之后」或「该日期之前」
- **初次投放时间**——选起止日期，筛出这段时间内初次投放的短剧，规则同上；**从没投过的短剧（显示 `—`）会被排除**，只填一端也一样
**一次筛一批剧**：短剧名和剧本编号两个框右侧各有一个「批量」按钮，点一下变成多行输入框，**每行填一个值**，一次就能筛出十几部。批量模式下只认换行——逗号不算分隔符，`LA001,LA003` 会被当成一个编号、什么都筛不到。再点一下（此时按钮显示「单独」）切回单行输入。切换时已填内容会带过去，不会丢。
清单里还有两列时间信息：
| 列 | 说明 |
|---|---|
| 上线时间 | 这部剧的上线 / 预上线时间 |
| 初次投放时间 | 这部剧第一次被投放的时间，从未投放过显示 `—`。该值来自上游系统，与本系统有没有发起过测新无关 |
列表默认每页 10 条，可切换 20 / 50 条，底部显示「共 N 部 · 第 x/y 页」。点「查询」后回到第 1 页。
### 3.3 批量发起测新
勾选要测的短剧后，顶部批量区显示「已选 N 部短剧」，点「批量发起测新」进入确认弹窗。
测新**只能批量发起**，没有逐条发起的入口。只想测一部，就只勾那一部。
**勾选框被禁用的行**：已通过测新的短剧不可重复发起，勾选框是灰的，鼠标悬停提示「已通过测新」。表头的全选框会自动跳过这些行。
### 3.4 确认弹窗
「测新确认」弹窗一次性展示两项内容，核对无误后点「通过并绑定」：
| 看什么 | 内容 | 能不能改 |
|---|---|---|
| 默认自动化任务配置 | 按语种列出本批会绑定到的 Meta / TikTok 任务 | 不能，弹窗只展示 |
| 本次批量发起测新 · 逐部设排期（东八区）| 你勾选的短剧清单（剧本编号 + 短剧名），每部短剧各一个排期输入 | 能改；留空 = 立即执行 |
两个要点：
- 排期**逐部设**，同一批里每部短剧可以给不同时间。排期输入框只在该剧的「初次投放时间」**还没到**（晚于当前东八区时间）时自动带出；从没投过的剧（清单里显示 `—`）或初次投放时间已经过去的剧，默认留空，等于立即投放。
- 配置列表里显示「未配置」的语种，本批中属于该语种的短剧**会被跳过**，其余语种照常绑定。
> 预上线短剧建议设置排期，让它到上线时间再投。排期只是传给自动化任务的参数、由任务到点执行；点「通过并绑定」后，绑定动作是立即发生的。
### 3.5 确认之后
点「通过并绑定」后，本批短剧按各自语种分别绑定进 Meta 与 TikTok 的测新默认自动化任务，页面随后自动跳转到「运行看板 · 执行记录」，可直接核对结果。
若有短剧因语种未配置被跳过，会弹提示告知跳过数量。被跳过的短剧**保持未发起状态**，补配好该语种的默认自动化任务后可以重新发起。
### 3.6 易错点
- **发起前先看「默认自动化任务」页**。语种没配就发起，那几部会被跳过，白跑一趟。
- **排期是逐部设的**，别指望改一个输入框就覆盖全批；每部短剧都得看一眼。只有初次投放时间还没到的剧会自动带出；初次投放时间已过去或从没投过的剧默认为空（立即投放），这两类别漏看。
- **排期是东八区**，列表与设置界面都标注了。上游带下来的初次投放时间本身就是东八区，系统原样使用、不做换算；跨时区协作时别按本地时间再心算一次。
- **已通过不可重复发起**，勾选框会变灰。
- **取消不写入记录**。弹窗点「取消」后本批短剧保持未发起，不会留下痕迹。
- **测新没有驳回**。不想投就不勾选，不存在「发起后再驳回」这条路。
- **按「初次投放时间」筛不出没投过的剧**。显示 `—` 的短剧不属于任何时间区间，这个筛选只要填了任一端它们就会被排除。想找从没投过的剧，别用这个筛选。

## 4. 运行看板与跟投信号
运行看板只有「执行记录」一页；「跟投信号」是与之并列的独立页面（顶部导航里紧挨着测新清单）。两页都是纯读、没有任何写入口。
### 4.1 执行记录
它记录机器投放做过的全部编排动作。
筛选条件：
| 筛选项 | 说明 |
|---|---|
| 信号类型 | 测新 / 跟投 |
| 维度 | 短剧 / 广告计划 / 素材 |
| 目标 | 跨维度搜索，可输入短剧名、剧本编号、计划ID 或素材ID |
| 操作人 | 系统（自动触发）/ 运营A / 运营B / 运营C |
| 时间范围 | 起止日期 |
列表字段：
| 字段 | 说明 |
|---|---|
| 信号ID | 触发本次编排的信号标识 |
| 类型 | 测新（绿色）或跟投（蓝色）|
| 维度 + 目标 | 投的什么、投的谁 |
| 自动化任务ID | 绑定到的 Meta / TikTok 任务，形如 `meta_kr_test / tt_kr_test`。同一个键配了多条时，会把这些任务全列出来（用「、」分隔）|
| 操作人 | 确认人（测新与跟投均为人工作出的确认）|
| 运行 | 见下表 |
| 时间 | 信号接收与绑定时间 |
**「运行」列有两种形态，务必分清：**
| 显示 | 含义 |
|---|---|
| 启动（绿点）| 已成功绑定，且自动化任务处于启用状态 |
| 暂停 | 已绑定，但自动化任务处于暂停状态 |
| 灰色文本（如「跳过·无默认自动化任务」「跳过·数据异常」）| 没绑上。灰色文本写的就是原因，不是任务状态 |
绑定环节没有独立列：绑定失败或被跳过时，原因直接以文本并进「运行」列。所以**看到灰色文本就意味着这次编排没成功**，通常是某个语种缺配置。
列表默认每页 10 条，可切换 20 / 50 条，底部显示「共 N 条 · 第 x/y 页」。点「查询」后回到第 1 页。
### 4.2 跟投信号
这一页是**跟投的入口**。上游决策系统判定某个目标值得放量后，信号会落到这里，状态是「待确认」——**在你确认之前，系统不会投出去一分钱**。
它和执行记录的分工：执行记录看「绑成了什么」，这里看「收到了什么」。
筛选条件：维度 / 语言 / 状态 / 目标 / 接收时间范围。
| 列 | 说明 |
|---|---|
| 勾选框 | 只有「待确认」的能勾；「已绑定」的是灰的。表头全选框会自动跳过已绑定的行，且只勾当前页 |
| 接收时间 | 系统收到这条信号的时间 |
| 信号ID | 信号的唯一标识。上游产出的同一条信号重复投递，系统只受理一次 |
| 维度 | 短剧 / 广告计划 / 素材 |
| 目标ID | 上游给的投放目标标识 |
| 短剧名 | 能对上库里剧目时显示「剧本编号 + 中文剧名」，对不上就用上游给的名字 |
| 语言 / 剧本 | 上游给的语言与剧本编号，原样展示 |
| 置信度 | 上游判定这个目标的把握程度，0–100%。它表示阶段判定的可信度，与盈利概率无关 |
| 原因 | 上游为什么判定它值得跟投，例如「成长期: ROI>175.0% 且趋势上升71%」|
| 状态 | 待确认（还没投）/ 已绑定（已投出去）|
| 详情 | 点「查看」看这条信号的完整原始数据 |
列表默认每页 10 条，可切换 20 / 50 条，底部显示「共 N 条 · 第 x/y 页」。点「查询」后回到第 1 页。
**勾选跨页保留**：在第 1 页勾了几条、翻到第 2 页再勾几条，之前勾的不会丢，可以一次批量确认。表头的全选框只勾当前页。

**批量确认**（跟投只能批量确认，没有逐条确认的入口）：
1. 勾选要确认的信号——只想确认一条，就只勾那一条
2. 点顶部「批量确认」，弹窗展示三件事：本次批量确认的**信号清单**、这批信号会用到的**默认自动化任务配置**（按「目标维度 × 语种」列出，没配的标「未配置」）、**本批统一排期**
3. 核对无误后点「通过并绑定」

| 弹窗里看什么 | 内容 | 能不能改 |
|---|---|---|
| 本次批量确认 | 你勾选的信号（维度 + 短剧名）| 不能，要改就取消后重选 |
| 默认自动化任务配置 | 本批涉及的「目标维度 × 语种」组合会绑到哪两平台任务 | 不能，弹窗只展示 |
| 排期（东八区）| 一个时间，对本批所有信号生效 | 能改；留空 = 立即执行 |

确认之后：
- 各信号按自己的「目标维度 × 语种」绑定，页面自动跳到「运行看板 · 执行记录」
- 配置列表里显示「未配置」的组合，本批中属于该组合的信号**会被跳过**，弹提示告知跳过数量；这些信号**保持待确认**，补配好之后可以重新勾选确认
- 点「取消」不写入任何记录，信号保持待确认

## 5. 默认自动化任务
### 5.1 它是什么
这是后台维护的绑定配置表：测新按语种、跟投按「目标维度 × 语种」。你发起测新或信号到达时，系统按对应的键查这张表，解析出要绑的目标任务。
一条配置由四部分组成：**键**（测新 = 语种；跟投 = 目标维度 × 语种）、**绑定 Meta 自动化任务**、**绑定 TikTok 自动化任务**、**状态**（启用 / 停用）。
页面顶部有两个场景页签，两者的归属和维护方式不同：

| 页签 | 键 | 谁能看到 | 这一版归谁 |
|---|---|---|---|
| 测新 | 语种 | 所有人 | 按操作人分开——你在本页看到和维护的是你自己那一版，别人配的不影响你 |
| 跟投 | 目标维度 × 语种 | 仅管理员 | 「系统」全局一版，全公司共用；跟投信号到达时按它解析 |

跟投多一个「目标维度」（短剧 / 广告计划 / 素材）：同一个语种下，短剧级、广告计划级、素材级各配一组，**互不通用**。所以跟投页签的表里多一列「目标维度」。
跟投配置是系统级的一版、全公司共用，不该有个人之分，所以归「系统」、由管理员维护；普通用户看不到跟投页签。但跟投的**确认动作不设管理员限制**——跟投信号页所有人可见、均可确认。
**同一个键可以配多条**。比如给「韩语」配两条测新默认任务，一次批量测新就会把短剧绑进这四条任务（两条 Meta + 两条 TikTok）。跟投的同一个「目标维度 × 语种」同理。所以配了几条，就决定一次会投到几处。
**每条各自带启用 / 停用状态**，只影响它自己：
| 状态 | 含义 |
|---|---|
| 启用 | 参与解析，目标会绑进它的任务 |
| 停用 | 完全不参与——不绑定，也不报错 |
临时想收口某个账户包，把对应那条停用就行，配置留着随时能恢复，不必删。
> 页面只列你**已配置**的条目，不是全部语种。没配过的语种不会出现在列表里——这正是要留意的地方，见 §5.4。
### 5.2 新增配置
点右上角「新增配置」，弹窗里填三件事：
| 字段 | 怎么填 |
|---|---|
| 目标维度 | 只有跟投页签有：短剧 / 广告计划 / 素材 |
| 语种 | 下拉选择 |
| 绑定 Meta 自动化任务 | 搜索框，输入关键字筛选后选中；候选任务从 Meta 自动化任务系统拉取 |
| 绑定 TikTok 自动化任务 | 同上，候选来自 TikTok 自动化任务系统 |
两个平台都可以选「未配置」，但**至少要给一个平台绑定任务**，两个都空不允许保存。
**不限制重复**：同一个键已经配过，照样可以再配一条——它作为一条新条目追加进去，不会覆盖、也不会报错。
**素材维度只能挑指定了素材类型的任务**：目标维度选「素材」时，两个平台的任务下拉只列出带素材类型的任务（如「英语跟投·素材·视频」）；短剧、广告计划维度不受这个限制，任务全都能选。
### 5.3 编辑、启停与删除
每行右侧有三个操作：
- **编辑**——打开编辑弹窗，键固定不可改（跟投的目标维度与语种也固定），只调整两个平台各自绑定的任务
- **启用 / 停用**——点一下切换这一条的状态，按钮文案随之在「停用」「启用」之间变化；停用的行状态列显示灰色「停用」
- **删除**——只删掉这一条。若删的是该键下唯一启用的那条，二次确认会额外提示「删除后……将没有启用中的默认任务，会跳过并告警」
删错了重新「新增配置」配一条即可，已经产生的执行记录不受影响。
### 5.4 没配置的后果
某个键下**没有启用中的默认任务**（压根没配，或者配了但全被停用），系统不会报错，但会在两处露出来：
- 发起测新时，确认弹窗的配置列表里该语种显示「未配置」，本批中该语种短剧被跳过
- 执行记录里，「运行」列显示灰色文本「跳过·无默认自动化任务」

跟投同理，只是键是「目标维度 × 语种」：配了「短剧 × 韩语」不等于「素材 × 韩语」也配好了，后者来了照样跳过。跟投在批量确认时跳过会弹提示告知数量；被跳过的信号保持待确认。所以要开跟投，得把**每个要投的维度 × 语种组合**都配上。
所以看到灰色文本，第一件事就是回本页补配置，或把停用的那一行重新启用。

## 6. 你能看到什么（权限）
| 项目 | 普通用户 | 管理员 |
|---|---|---|
| 测新清单 | 所有人看到的是同一份清单，均可发起测新 | 同左 |
| 默认自动化任务 · 测新 | 可增删改自己那一版 | 同左 |
| 默认自动化任务 · 跟投 | 看不到该页签 | 可增删改「系统」全局那一版 |
| 操作记录 | 仅可查看自己的操作记录 | 可查看全部 |
测新入口不分发到人，没有按人分配。要看同事的操作记录，找管理员。

## 7. 术语表
| 术语 | 含义 |
|---|---|
| 测新 | 新剧上线后的小规模试探性投放，需人工从测新清单勾选发起 |
| 跟投 | 上游决策系统判定某目标值得继续投放后，信号入「跟投信号」页待确认；勾选批量确认后才绑定进跟投任务。配置仅管理员可维护 |
| 新上线 | 短剧由上线信号提醒进入清单时的标记，仅提醒、不自动投 |
| 剧本编号 | 短剧所属剧本的编号，形如 `LA001` |
| 默认自动化任务 | 后台维护的绑定配置表：测新按「语种」、跟投按「目标维度 × 语种」；同一个键可配多条，每条带启用 / 停用状态 |
| 自动化任务 | Meta / TikTok 自动化任务系统中的既有任务对象，承载账户包、预算、竞价等全部执行参数 |
| 绑定 | 机器投放对投放对象的唯一动作：把短剧分别绑进解析出的两个平台任务，不新建任务 |
| 排期 | 投放开始时间，时区固定东八区；未设置即立即执行。测新逐部设（仅当初次投放时间晚于当前东八区时间时默认带出），跟投本批统一设 |
| 监测链接·机器投放 | 由机器投放绑定流程触发的投放，其监测链接标记为「机器投放」，便于与手动 / 批量创建的投放区分对账 |

## 8. 常见问题
**发起测新后，有几部短剧没进执行记录？**
大概率是该语种没配默认自动化任务、被跳过了。弹窗会提示跳过数量，去「默认自动化任务」页补配后重新发起。
**执行记录的「运行」列为什么显示灰色中文？**
那不是任务状态，是绑定没成功的原因（如「跳过·无默认自动化任务」）。绑定成功的会显示绿色的「启动」或「暂停」。
**测新确认弹窗里能不能改绑自动化任务？**
不能，弹窗只做展示。要改去「默认自动化任务」页，用「编辑」，或删掉重新新增。
**排期是每部短剧单独设吗？**
测新是，弹窗里每部短剧各一个排期输入，只有初次投放时间还没到的剧会自动带出该时间，想改就直接改。跟投不是，跟投本批共用一个排期。
**已通过的短剧为什么勾不上？**
已通过不可重复发起，勾选框是灰的，悬停会提示「已通过测新」。
**发起错了能撤回吗？**
没有撤回。确认后绑定立即发生并写入执行记录。弹窗阶段的「取消」是唯一中止点，取消不写入记录。
**看不到同事发起的测新？**
权限设计如此，操作记录按人可见，找管理员查看。
**列表里只有几个语种，其他语种去哪了？**
本页只列你已配置的条目。要投的语种没出现在列表里，说明还没配，点「新增配置」补上。
**跟投页签为什么看不到？**
那是跟投的**配置**页签，归「系统」全局一版、由管理员维护，普通用户看不到。跟投**信号**页是所有人可见的，确认跟投就在那里做。
**跟投信号不确认会怎样？**
它一直停在「待确认」，系统不会投出去。要投就得勾选后点「批量确认」——跟投没有自动投放这条路。
**勾了「通过并绑定」，为什么有几条没投出去？**
那几条的「目标维度 × 语种」组合没有启用中的默认任务（弹窗的配置列表里会显示「未配置」）。确认时会弹提示告知跳过数量，这些信号**保持待确认**，补配好配置、或把停用那行重新启用后，重新勾选确认即可。
**翻页以后，之前勾的信号 / 短剧还在吗？**
在。勾选跨页保留，翻页只是换一屏，不会清掉已勾的，可以挑完几页再一起提交。表头的全选框只勾当前页，不会波及其他页。
**怎么知道系统到底收到了哪些跟投信号？**
顶部导航的「跟投信号」页。它列出全部收到的信号，含上游给的原因、置信度和状态。确认跟投和排查「这条为什么没投」都在这一页。
**同一个语种配了两条，会投两份吗？**
会。该键下所有启用中的条目都会生效，一次绑定把目标绑进它们的全部任务。只想要一条时，把多余的那条停用或删掉。
**停用和删除有什么区别？**
停用只是这一条不生效，配置留着、随时点回来；删除是彻底去掉。临时收口用停用，配错了用删除。
**跟投会跟我发起的测新冲突吗？**
不会互斥。同一部短剧可以同时在测新任务和跟投任务里，各投各的；重复消耗由自动化任务自己的预算与止投规则约束。
