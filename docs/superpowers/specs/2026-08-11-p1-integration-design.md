# P1 集成设计（序6 · 三步链路打通 + 机器投放替换节奏）

> 日期：2026-08-11 · 状态：草稿待审 · 关联：《项目整体规划》（M1 线① P1 集成、待对齐决策 #1）
> 本文档是六个模块设计的最后一个（序6），定义素材生产→打分→投放三环节的打通需求，以及机器投放对三步流水线的替换节奏。

## 1. 定位与范围

P1 集成是全链路「初始投放」环节：打通素材生产（narration）→ 打分（short-drama-scoring）→ 投放（auto_delivery）三环节，**定时自动跑通、人工抽查**。与机器投放（跟投）构成全链路的两段：P1 负责新素材初始投放，机器投放（序1-5）负责已投素材跟投。

**替换节奏**：机器投放 MVP（09-30）上线后，三步流水线暂并行；经固定观察期评审，双达标后三步流水线退役、机器投放接管。

**本期做**：三步链路定时自动打通（含三环节衔接契约）、人工抽查机制、替换节奏定义。
**本期不做**：素材-短剧绑定（素材生产环节已含短剧归属）、打分模型训练/推理（打分消费方既有能力）、机器投放执行侧（序1-5）、生命周期判定/策略匹配（决策端 smart_ad_put 职责）。

## 2. 三步链路需求

### 2.1 定时调度

- 定时自动触发全链路，无需人工逐环节确认。
- 人工抽查：异常时告警，人工介入确认；正常运行不打扰。

### 2.2 环节衔接契约

| 环节 | 产出 | 消费方 |
|---|---|---|
| 素材生产（narration） | 素材文件 + 元数据（**含短剧归属**、语言、素材 ID） | 打分、投放 |
| 打分（short-drama-scoring） | 素材分数（0-100） | 投放（排序参考） |
| 投放（auto_delivery） | 建任务 → 平台 task_id | 数据回流（经序2 数据管道） |

- **素材-短剧绑定由素材生产环节完成**：narration 输出即携带短剧归属，三步链路与机器投放均不额外绑定。此为机器投放「绑定由上游保证、执行端不绑定」（序1/序4）的上游来源。
- **打分作用为排序参考**：分数作投放优先级参考，不硬性过滤低分素材。
- **投放输入**：按分数排序选取素材 + 元数据（短剧归属/语言），直接建任务，不查绑定。

### 2.3 人工抽查

- 全链路定时自动执行，异常（环节失败/产出缺失/分数异常）时告警。
- 人工抽查运行状态与投放产出，确认链路健康。

## 3. 与机器投放的边界

```
P1 三步链路（初始投放）         机器投放（跟投）
素材生产→打分→投放              决策端 smart_ad_put → 执行端建任务/跨账户复制
        │  投放数据回流（序2 数据管道）
        └──────────────────────────────────→ 决策端判定 → 跟投
```

- **并行职责**：P1 三步流水线负责新素材初始投放；机器投放负责已投素材跟投，二者不同职责、并行运行。
- **数据回流**：P1 初始投放的投放数据经序2 数据管道回流，供 smart_ad_put 生命周期判定，触发机器投放跟投。

## 4. 替换节奏（三步流水线退役）

- **MVP 后并行**：09-30 机器投放上线后，三步流水线暂并行，不立即下线。
- **固定观察期**：上线后设观察期（建议 2-4 周，具体待对齐），评估机器投放运行质量。
- **到期评审**：
  - **双达标**（执行稳定 + 业务效果，口径见下）→ 机器投放扩展接管新剧初始投放（新剧规则化投放），三步流水线退役。
  - **未达标** → 继续并行，进入下一观察期再评审。
- **稳定判定口径（双达标）**：
  - 执行稳定：跟投成功率 ≥ 阈值、幂等无重复任务、无误投/错投、决策端数据准确。
  - 业务效果：跟投 ROI/消耗表现与人工持平或更优（需对比基准）。
- **决策人**：业务/项目负责人（具体归属待对齐）。

## 5. 验收口径

- 三步链路定时自动跑通：素材生产→打分→投放无人工逐环节介入，产出可查。
- 素材生产输出含短剧归属，链路与机器投放不额外绑定。
- 打分输出为排序参考，不硬性过滤。
- 替换节奏可执行：观察期起止明确、评审口径可量化、退役决策有据可依。

## 6. 依赖与待对齐

- **依赖**：素材生产（narration）、打分（short-drama-scoring）、投放（auto_delivery）三环节既有能力；序2 数据管道（投放数据回流）；机器投放 MVP（序1-5）上线。
- **待对齐**：
  - 观察期时长（建议 2-4 周）与评审时点
  - 稳定判定量化阈值（成功率阈值、业务效果对比基准）
  - 退役决策人归属
  - 三步链路定时频率（建议对齐 30min 调度）
  - 打分排序参考在投放中的具体应用（排序规则/人工可见）
- **假设**：素材生产输出元数据已含短剧归属；三步流水线退役前机器投放已具备新剧初始投放能力（新剧规则化投放），否则退役后新剧投放职责需另行承接。
