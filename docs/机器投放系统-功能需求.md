# 机器投放系统 · 功能需求文档（PRD）

> 版本 v1.1 · 面向开发 · 取代原六份 spec 的执行侧设计

## 1. 概述

### 1.1 系统定位

机器投放系统是**触发编排层**：接收触发信号，**把目标（短剧/素材/广告计划）分别绑定进 Meta 与 TikTok 两平台的默认自动化任务**。系统自身不创建广告、不维护账户池、不跨账户复制——这些能力全部由既有**自动化任务执行层**承担。

> 术语说明：本文档「自动化任务」指 **Meta 自动化任务系统 / TikTok 自动化任务系统** 中的既有任务对象，直接承载账户包/预算/竞价等全部执行参数及其绑定短剧；机器投放不复制定义、不维护任务明细，仅引用（绑定）目标任务。
> 术语说明：「默认自动化任务」指机器投放后台维护的绑定配置表：**场景 × 语种**（测新按当前操作人逐人维护、跟投归系统）→ 各绑一条 **Meta 自动化任务** 与一条 **TikTok 自动化任务**。信号到达后机器投放按该表解析目标任务并绑定。

### 1.2 核心价值

把两件本由运营/优化师手动做的事，变成自动触发：

1. **新剧测新**：剧上线 → 自动生成测新清单 → 人工确认（分别选定 Meta / TikTok 任务）→ 绑定到两平台测新任务并投放。
2. **跟投**：smart_ad_put 看数据决策 → 按默认绑定自动绑定进 Meta / TikTok 跟投任务并投放。

### 1.3 两条路径对比

| 维度 | 新剧测新 | 跟投 |
|---|---|---|
| 触发源 | 剧上线事件 | smart_ad_put 决策 |
| 是否人工确认 | 是（清单 + 确认）| 否（全自动）|
| 目标粒度 | 短剧 | 短剧 / 广告计划 / 素材 |
| 素材 | 指定筛选模式 | 随决策目标 |

## 2. 核心概念：触发信号

机器投放系统的唯一输入是触发信号，共两类。

### 2.1 信号公共字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `signal_id` | string | ✅ | 信号唯一标识，幂等键，重复投递不重复绑定 |
| `signal_type` | enum | ✅ | `NEW_DRAMA_ONLINE` / `FOLLOW_UP` |

### 2.2 `NEW_DRAMA_ONLINE`（新剧上线）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `shortplay_id` | string | ✅ | 上线短剧 ID |
| `shortplay_name` | string | ✅ | 短剧名 |
| `script_no` | string | ✅ | 剧本编号（如 `LA001`），与 `shortplay_name` 拼接展示 |
| `language_code` | string | ✅ | 短剧语言，用于默认自动化任务路由 |
| `online_at` | datetime | ✅ | 上线时间 |

> 展示规则：短剧在后台展示时，名称格式为「剧本编号 + 短剧名」，如 `LA001 霸总的替嫁新娘`。业务上短剧分两级——剧本（编号 `LAxxx`）与短剧，后台展示短剧需带上所属剧本编号。

### 2.3 `FOLLOW_UP`（跟投决策）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `target_dimension` | enum | ✅ | `product` / `campaign` / `material` |
| `target_id` | string | ✅ | 对应 shortplay_id / campaign_id / material_id |
| `script_no` | string | 否 | 目标为短剧时携带剧本编号（如 `LA001`），展示时与短剧名拼接 |
| `reason` | string | 否 | 决策理由（可读，用于看板展示）|

> 跟投的决策统一由 smart_ad_put 产出（含素材级，素材级决策能力由其补齐）。

## 3. 功能一：新剧测新

### 3.1 功能说明

新剧上线后，系统在该剧预生产素材就绪时，自动生成测新清单，经人工确认后绑定到 Meta 与 TikTok 的测新默认任务并投放。

### 3.2 触发规则

- 触发条件：短剧进入「已上线」状态，且该剧**预生产素材已就绪**。
- 触发模式：**默认自动 + 可手动**。默认剧上线即自动生成清单；特定剧可配置关闭自动，改人工发起。

### 3.3 处理流程

```
剧上线 → 检查素材就绪 → 生成测新清单 → 人工确认（分别选定 Meta / TikTok 自动化任务）→ 绑定完成
```

### 3.4 人工确认规则

人工确认是测新流程唯一介入点，需处理三件事：

1. **绑定自动化任务**：系统按该清单语种预选默认绑定中的 Meta / TikTok 两条任务（搜索下拉，可分别换绑，见 §5.1）。
2. **选素材**：两种模式二选一（见 3.7）。
3. **设排期**：可设投放排期时间，未设默认立即投放。

确认动作的结果：**通过 / 换绑（任一平台任务）/ 驳回 / 排期通过**。人工不逐个确认预算、竞价等详细参数（由自动化任务承载）。

测新清单支持按状态、短剧、时间筛选；其中短剧筛选支持输入**短剧名或剧本编号**（如 `LA001`）检索。

支持**批量操作**：可勾选多条「待确认」清单，批量通过 / 批量驳回；**批量通过时可同时设定统一排期**（东八区，留空=立即投放）。不可操作状态（等待素材 / 已通过 / 已驳回）的清单不可勾选。

支持**排期**：清单可设投放排期时间，**到点由系统自动触发投放任务**（非仅列表展示）。排期时区为**东八区**，列表展示与设置界面均须标注。未设排期默认立即投放。

### 3.7 素材选择（双模式）

测新的素材选择支持两种模式，**二选一、互相隔离，最终只取当前模式的选择**：

**智能推荐**（默认）：
- 机器按素材**内容评分**降序排列，自动选取前 **Top N** 个素材。
- N 默认 10，可人工调整；调整后重新按新 N 取 Top N。
- 推荐素材直接展示为可移除标签，无需逐个勾选。

**指定素材**：
- 人工从素材库弹窗搜索、勾选具体素材（卡片网格，含语言/投放者/剧本/短剧筛选）。
- 勾选确认后回填为已选素材标签，可移除。

> 两种模式切换时清空对方的选择（严格隔离），避免混淆。内容评分来自素材生产的 prompt 评分（1-10 分），效果评分投后才有、不参与测新选材。

### 3.5 异常与边界

| 场景 | 处理 |
|---|---|
| 素材未就绪 | 跳过，等待素材就绪后重新触发 |
| 无默认自动化任务（该语言在默认绑定表未配置）| 跳过并告警 |
| 人工驳回 | 不投，清单标记驳回，不绑定、不投放 |
| 同一 signal_id 重复 | 幂等去重，不重复生成清单 |

### 3.6 验收

- [ ] 剧上线且素材就绪后，自动生成测新清单
- [ ] 人工确认通过后，短剧成功绑定进 Meta 与 TikTok 两条测新任务
- [ ] 同 signal_id 重复投递不重复生成清单

## 4. 功能二：跟投

### 4.1 功能说明

smart_ad_put 根据投放数据判定某目标值得继续投放时，系统按默认绑定解析 Meta / TikTok 跟投任务并自动绑定，无需人工介入。

### 4.2 触发规则

- 触发源：smart_ad_put 决策。
- 模式：**全自动，无人工确认**。

### 4.3 处理流程

```
smart_ad_put 决策 → 按语种解析默认绑定 → 绑定进 Meta / TikTok 跟投自动化任务
```

### 4.4 异常与边界

| 场景 | 处理 |
|---|---|
| 决策数据异常（必填字段缺失）| 跳过并告警 |
| 无默认自动化任务（该语种未配置）| 跳过并告警 |
| 同 signal_id 重复投递 | 幂等去重，不重复绑定 |

### 4.5 验收

- [ ] 决策产生后自动绑定进对应 Meta / TikTok 跟投任务
- [ ] 决策 → 绑定完成，可在执行记录查询（两平台）
- [ ] 同 signal_id 重复投递不重复绑定

## 5. 公共规则

### 5.1 默认自动化任务（路由与绑定）

- 后台维护「默认自动化任务」表：维度 = **场景（测新 / 跟投）× 语种**；测新按当前操作人逐人维护一版，跟投统一归「系统」一版。
- 每一格（场景 × 语种）**分别绑定一条 Meta 自动化任务与一条 TikTok 自动化任务**，下拉数据从各自自动化任务系统拉取，提供搜索/换选。
- 后台以**正交表**列出全部「场景 × 语种」组合（含未配置）并直接在格内编辑，无独立新增弹窗；未配置的组合，对应场景+语种信号将跳过并告警。
- 信号到达后：按信号「场景 + 语种」解析（测新取当前操作人一版、跟投取系统一版）→ 得到 Meta / TikTok 两条目标任务 → 目标分别绑定进两条任务。

### 5.2 自动化任务（外部系统）

- 自动化任务 = Meta / TikTok 自动化任务系统中的既有任务对象，机器投放**不复制定义、不维护任务明细**。
- 任务直接承载全部执行参数（账户包/账户数/预算/竞价/优化目标/版位/定向/投放天数/止投）及其绑定短剧，均在任务系统侧管理。
- 机器投放仅通过「默认自动化任务」表引用（绑定）目标任务，不再维护「模板」「自动化任务配置」等中间层。

### 5.3 与执行层的边界

- 机器投放系统对投放对象的**唯一动作是：把目标分别绑定进解析出的 Meta / TikTok 默认自动化任务**，不再新建任务。
- 绑定传入：`shortplay_id` / `target_id` + 默认绑定解析结果（平台 + 任务）。

### 5.4 信号通道

- 机器投放系统提供一个信号入口，接收 smart_ad_put 决策与剧上线事件。
- 具体实现（文件/API/MQ）不锁，开发阶段定。

### 5.5 幂等

- 以 `signal_id` 为幂等键，同信号重复投递不重复绑定。

## 6. 执行记录与看板

系统保留**管理看板**，纯读、无写入口，三页：运行概览 / 执行记录 / 投放结果。异常以执行记录状态与日志呈现，不设独立告警页。

### 6.1 运行概览

展示机器投放自身近期的编排情况，不含业务指标（消耗/ROI 属投放结果视角）。

| 指标 | 数据来源 | 说明 |
|---|---|---|
| 收到信号数 | 编排记录（signal_id 去重）| 累计/今日接收的触发信号数 |
| 绑定成功 / 失败 / 跳过 | 编排记录 | 按绑定结果计数 |
| 待确认清单数 | 测新清单 | 待人工确认的测新清单数 |
| 无默认自动化任务 / 素材未就绪跳过 | 编排记录 | 异常跳过统计 |

### 6.2 执行记录

展示机器投放的全部编排动作留痕，涵盖测新与跟投两类信号。

| 字段 | 说明 |
|---|---|
| signal_id | 信号唯一标识 |
| signal_type | 测新 / 跟投 |
| target_dimension + target_id | 目标（短剧/广告计划/素材）|
| 绑定任务 | 默认绑定解析的 Meta / TikTok 任务 |
| 自动化任务ID | 绑定到的 Meta / TikTok 任务标识（各平台一条；多个信号可绑同一任务）|
| 状态 | 当前状态（见 6.6 状态列表）|
| 时间 | 信号接收与绑定时间 |

支持筛选：信号类型 / 状态 / 时间范围 / target_id。

> 测新的「待确认」阶段由「测新清单」管理；人工确认通过、绑定完成后，其动作计入本页执行记录。

### 6.6 编排状态模型

一次编排动作从信号接收到绑定自动化任务、再到任务内部跑完，经过**三个环节**。每个环节有独立的状态，横向依次展示，构成一条编排的状态链：

```
绑定 → 运行 → 广告创建
```

执行记录与运行概览的「状态」列，横向展示这三个环节各自的状态值；某一环节未到时以「—（待定）」表示，前置环节失败/跳过时后续环节不再展示。

**环节一：绑定（机器投放自身 → Meta / TikTok 自动化任务）**

| 状态值 | 含义 |
|---|---|
| `排期中` | 清单已确认、已设排期，等待到触发时间 |
| `绑定中` | 信号已接收，正在调用任务系统绑定接口 |
| `成功` | 目标已绑定进解析出的 Meta / TikTok 默认任务 |
| `部分成功` | 仅一个平台绑定成功（如 Meta 成功、TikTok 失败）|
| `失败` | 调用绑定接口失败 |
| `跳过·无默认自动化任务` | 该语言在默认绑定表未配置 |
| `跳过·素材未就绪` | 测新预生产素材未备好 |
| `跳过·数据异常` | 信号必填字段缺失 |
| `已驳回` | 测新人工驳回 |

**环节二：运行（直接取自动化任务的运行状态）**

| 状态值 | 含义 |
|---|---|
| `启动` | 自动化任务处于启用状态 |
| `暂停` | 自动化任务处于暂停状态 |

**环节三：广告创建（自动化任务一轮执行结果）**

| 状态值 | 含义 |
|---|---|
| `成功` | 本轮广告全部建成功 |
| `部分成功` | 部分账户/素材建成功（如 N 个账户中 M 个成功）|
| `失败` | 本轮广告未建出 |

> 关键：状态链是**三环节各自独立取值**，不是单一状态。例：某编排「绑定=部分成功、运行=启动、广告创建=成功」，表示目标只绑进了一端平台任务、该端任务启动并建出广告。

### 6.3 投放结果

透传 Meta / TikTok 两个自动化任务系统的投放结果，供人工巡检。

| 页面 | 透传内容 |
|---|---|
| 自动化任务列表 | 两平台的自动化任务及其状态（含平台维度）|
| 广告系列 | 广告系列状态/预算/竞价策略/账户 |
| 广告组 / 广告 | 逐级透传，含商品库关联、行动号召 |

该页等同两个执行层现有「自动化任务 / 广告系列 / 广告组 / 广告」列表的只读视图。

### 6.4 异常提示

异常（无默认自动化任务 / 素材未就绪 / 决策数据异常 / 绑定连续失败 N 次）以执行记录中的状态与运行日志呈现，不设独立告警页面。
