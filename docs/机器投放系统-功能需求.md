# 机器投放系统 · 功能需求文档（PRD）
> 版本 v1.3 · 面向开发 · 取代原六份 spec 的执行侧设计
## 1. 概述
### 1.1 系统定位
机器投放系统是**触发编排层**：接收触发信号，**把目标（短剧/素材/广告计划）分别绑定进 Meta 与 TikTok 两平台的默认自动化任务**。系统自身不创建广告、不维护账户池、不跨账户复制——这些能力全部由既有**自动化任务执行层**承担。

> 术语说明：本文档「自动化任务」指 **Meta 自动化任务系统 / TikTok 自动化任务系统** 中的既有任务对象，直接承载账户包/预算/竞价等全部执行参数及其绑定短剧；机器投放不复制定义、不维护任务明细，仅引用（绑定）目标任务。

> 术语说明：「默认自动化任务」指机器投放后台维护的绑定配置表：**场景 × 语种**（测新按当前操作人逐人维护、跟投归系统）→ 各绑一条 **Meta 自动化任务** 与一条 **TikTok 自动化任务**。信号到达后机器投放按该表解析目标任务并绑定。
### 1.2 核心价值
把两件本由运营/优化师手动做的事，变成自动触发：

1. **新剧测新**：剧上线 / 预上线（信号仅提醒，新剧入测新清单）→ 用户勾选短剧批量发起测新 → 弹窗确认默认自动化任务配置列表并设本批统一排期 → 按各短剧语种自动绑定到 Meta / TikTok 测新默认任务并投放，跳转执行记录查看结果。素材不在此环节选定，由自动化任务按「最近上传」扫描获取。
2. **跟投**：smart_ad_put 看数据决策 → 按默认绑定自动绑定进 Meta / TikTok 跟投任务并投放。本期暂不开发，设计时考虑留好入口。
### 1.3 两条路径对比
| 维度 | 新剧测新 | 跟投 |
|---|---|---|
| 触发源 | 短剧上线 / 预上线（信号仅提醒入测新清单），用户批量发起测新 | 智能基建决策 |
| 是否人工确认 | 是（弹窗确认默认配置列表 + 本批统一排期）| 否（全自动）|
| 目标粒度 | 短剧 | 短剧 / 广告计划 / 素材 |
| 素材 | 由自动化任务按「最近上传」扫描获取 | 随决策目标 |

> 触发源说明：无法监控到上线 / 预上线事件时，以上线 / 预上线时间作为当日的短剧触发口径。

## 2. 核心概念：触发信号
机器投放系统的唯一输入是触发信号，共两类。
### 2.1 信号公共字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `signal_id` | string | ✅ | 信号唯一标识，幂等键，重复投递不重复绑定 |
| `signal_type` | enum | ✅ | `NEW_DRAMA_ONLINE` / `FOLLOW_UP` |
### 2.2 `NEW_DRAMA_ONLINE`（新剧上线/预上线）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `shortplay_id` | string | ✅ | 上线短剧 ID |
| `shortplay_name` | string | ✅ | 短剧名 |
| `remark` | string | ✅ | 剧本编号（如 `LA001`），与 `shortplay_name` 拼接展示 |
| `language_code` | string | ✅ | 短剧语言，用于默认自动化任务路由 |
| `online_at` | datetime | ✅ | 上线 / 预上线时间 |

> 展示规则：短剧在后台展示时，名称格式为「剧本编号 + 短剧名」，如 `LA001 霸总的替嫁新娘`。业务上短剧分两级——剧本（编号 `LAxxx`）与短剧，后台展示短剧需带上所属剧本编号。

> 信号语义：`NEW_DRAMA_ONLINE` 仅提醒短剧上线 / 预上线、将新剧放入测新清单（带「新上线」标记），**不自动触发测新**；测新由用户从测新清单勾选短剧批量发起（见 §3）。
### 2.3 `FOLLOW_UP`（跟投决策）——即来自智能基建 smart_ad_put 项目
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `target_dimension` | enum | ✅ | `product` / `campaign` / `material` |
| `target_id` | string | ✅ | 对应 `shortplay_id` / `campaign_id` / `material_id` |
| `script_no` | string | 否 | 目标为短剧时携带剧本编号（如 `LA001`），展示时与短剧名拼接 |
| `reason` | string | 否 | 决策理由（可读，用于看板展示）|

> 跟投的决策统一由 smart_ad_put 产出（含素材级，素材级决策能力由其补齐）。

> 本期范围：smart_ad_put 系统本身尚未完成，两个系统的对接本期不做，待智能基建系统做完后再对接。本节信号定义保留，作为对接时的设计依据。
## 3. 功能一：新剧测新
### 3.1 功能说明
短剧上线 / 预上线后，新剧进入测新清单（`NEW_DRAMA_ONLINE` 信号仅提醒、不自动触发测新）。用户在测新清单勾选要测新的短剧，批量发起测新，弹窗一次性展示**默认自动化任务配置列表**（测新场景按各语种列出的 Meta / TikTok 绑定，仅展示不可修改，本批短剧按各自语种自动解析对应任务）并设**本批统一排期**，确认后按各短剧语种自动绑定到 Meta 与 TikTok 的测新默认任务并投放，全部确认完毕自动跳转执行记录查看绑定结果。素材不在此环节选定，由自动化任务按其素材筛选配置（选用「最近上传的素材」即可）多轮扫描获取新素材。

测新清单页展示全部短剧（新上线短剧带「新上线」标记），支持按语言 / 短剧名 / 剧本编号筛选并分页展示（每页 10 / 20 / 50）；勾选短剧后批量「发起测新」。短剧测新状态二态：未发起 / 已通过；已通过不可重复发起（勾选框禁用），不设驳回。
### 3.2 触发规则
- 触发条件：短剧进入「已上线」状态（预上线看预上线时间），不要求素材就绪。
- 触发模式：`NEW_DRAMA_ONLINE` 信号仅提醒（短剧上线 / 预上线后进入测新清单并标记「新上线」），不自动触发测新；测新由用户从测新清单勾选短剧批量发起，无自动分发。
### 3.3 处理流程
```
剧上线 / 预上线（信号仅提醒，新剧入测新清单）→ 用户勾选短剧批量发起测新 → 弹窗确认（展示默认自动化任务配置列表 + 设本批统一排期）→ 按语种自动绑定 Meta / TikTok 测新默认任务 → 跳转执行记录查看结果
```
### 3.4 人工确认规则
人工确认是测新流程的最终介入点（前置介入点为测新清单批量发起），以批量级弹窗一次性完成，展示两件事：

1. **默认自动化任务配置列表**：展示测新场景按语种的默认自动化任务绑定（Meta / TikTok 各一条，含未配置，见 §5.1），仅作确认展示、不可在弹窗内修改；本批短剧按各自语种自动解析对应 Meta / TikTok 测新默认任务（未配置语种确认时跳过并告警）。
2. **本批统一排期**：设一个投放排期时间，对本批所有短剧生效；留空默认立即投放，预上线短剧建议设置。

批量发起测新后，弹窗展示已选短剧清单（剧本编号 + 短剧名）、默认自动化任务配置列表与统一排期，确认动作结果：

- 通过并绑定：本批短剧按各自语种自动绑定进 Meta / TikTok 测新默认任务，写入执行记录（操作人 = 确认人）；无默认任务的语种跳过并告警。
- 取消：关闭弹窗，本批短剧保持未发起，可稍后重新发起。

人工不逐个确认预算、竞价等详细参数（由自动化任务承载），不在弹窗内改绑自动化任务（默认自动化任务页列表只读，改绑 = 删除后重新新增，见 §5.1）。确认完毕后自动跳转执行记录查看绑定结果。排期作为参数传入自动化任务排期字段，由任务到点执行，东八区，未设排期立即执行。
### 3.5 异常与边界
| 场景 | 处理 |
|---|---|
| 无默认自动化任务（该语言在默认绑定表未配置）| 弹窗列表中该语种行为「未配置」，确认时该短剧跳过并告警 |
| 同一 `signal_id` 重复投递 | 幂等去重，不重复提醒 / 不重复入测新清单 |
| 同一短剧重复发起测新 | 已通过不可再次发起（勾选框禁用）|
### 3.6 验收
- [ ] 剧上线 / 预上线后，新剧进入测新清单并标记「新上线」，不自动触发测新
- [ ] 用户从测新清单勾选短剧批量发起测新，弹窗展示默认自动化任务配置列表（场景 × 语种）与本批统一排期
- [ ] 确认后各短剧按语种自动绑定进 Meta 与 TikTok 测新默认任务，并写入执行记录
- [ ] 已通过短剧不可重复发起；未配置语种跳过并告警
- [ ] 确认完毕自动跳转执行记录查看绑定结果
- [ ] 同 `signal_id` 重复投递不重复提醒
## 4. 功能二：跟投
### 4.1 功能说明
> 本期不做：跟投依赖 smart_ad_put 产出 `FOLLOW_UP` 信号，而 smart_ad_put 系统尚未完成，本期先不做两系统对接，待智能基建系统做完后再做。本节内容保留为对接时的设计依据。

smart_ad_put 根据投放数据判定某目标值得继续投放时，系统按默认绑定解析 Meta / TikTok 跟投任务并自动绑定，无需人工介入。
### 4.2 触发规则
- 触发源：smart_ad_put 决策。
- 模式：全自动，无人工确认。
### 4.3 处理流程
```
smart_ad_put 决策 → 按语种解析默认绑定 → 绑定进 Meta / TikTok 跟投自动化任务
```
### 4.4 异常与边界
| 场景 | 处理 |
|---|---|
| 决策数据异常（必填字段缺失）| 跳过并告警 |
| 无默认自动化任务（该语种未配置）| 跳过并告警 |
| 同 `signal_id` 重复投递 | 幂等去重，不重复绑定 |
### 4.5 验收
- [ ] 决策产生后自动绑定进对应 Meta / TikTok 跟投任务（本期不做，待对接后验收）
- [ ] 决策 → 绑定完成，可在执行记录查询（两平台）
- [ ] 同 `signal_id` 重复投递不重复绑定
## 5. 公共规则
### 5.1 默认自动化任务（路由与绑定）
- 后台维护**「默认自动化任务」表**：维度 = 场景（测新 / 跟投）× 语种；测新按当前操作人逐人维护一版，跟投统一归「系统」一版。**本期仅提供测新配置**，跟投配置不建界面（跟投信号到达时仍按「系统」版默认绑定解析）。
- 每一条配置分别绑定一条 Meta 自动化任务与一条 TikTok 自动化任务，下拉数据从各自自动化任务系统拉取，提供搜索/换选。
- 配置页以**条目列表**展示当前操作人已配置的测新默认任务（不铺全量场景 × 语种组合）；顶部「新增配置」按钮录入（场景固定测新、选语种 + 逐平台绑定），**已覆盖的语种禁止重复新增**；配置列表只读（改绑 = 删除后重新新增），每行可删除，删除后该语种测新将跳过并告警。
- **列表只读**：配置仅测新，改绑 = 删除后重新新增；跟投全自动，按系统默认执行，无个人之分、无人工换选。
- 未配置的语种不出现在配置列表；对应语种测新在批量发起确认时于弹窗配置列表展示为「未配置」，确认时跳过并告警。
- 绑定解析：测新在用户批量发起、弹窗确认时按各短剧语种取当前操作人一版的默认绑定（弹窗仅展示配置列表；默认自动化任务页列表只读，改绑 = 删除后重新新增）；跟投在信号到达后按语种解析「系统」一版自动绑定。
### 5.2 自动化任务（外部系统）
- 自动化任务 = Meta / TikTok 自动化任务系统中的既有任务对象，机器投放**不复制定义、不维护任务明细**。
- 任务直接承载全部执行参数（账户包/账户数/预算/竞价/优化目标/版位/定向/投放天数/止投）及其绑定短剧，均在任务系统侧管理。
- 机器投放仅通过「默认自动化任务」表引用（绑定）目标任务，不再维护「模板」「自动化任务配置」等中间层。
### 5.3 与执行层的边界
- 机器投放系统对投放对象的**唯一动作是**：把目标分别绑定进解析出的 Meta / TikTok 默认自动化任务，不新建任务、不触碰任务命名。
- 绑定传入：`shortplay_id` / `target_id` + 排期（`schedule_at`，东八区，预上线必选）+ 默认绑定解析结果（平台 + 任务）。
- 素材不在测新环节传递：素材由自动化任务按其素材筛选配置（选用「最近上传的素材」即可）多轮扫描获取新素材。
### 5.4 信号通道
- 机器投放系统提供一个信号入口，接收 smart_ad_put 决策与剧上线事件。
- 具体实现（文件/API/MQ）不锁，开发阶段定。
### 5.5 幂等
- 以 `signal_id` 为幂等键，同信号重复投递不重复绑定。
### 5.6 权限
- **测新入口不分发**：所有用户可见相同的测新清单，均可发起测新（当前无按人分配规则；后续如需按人分配，先定义分配规则再补）。
- **操作记录按人可见**：普通用户仅可查看自己的操作记录；管理员可查看所有记录。
### 5.7 监测链接
- 监测链接创建类型与「手动 / 批量 / 自动化」区分开，新增「**机器投放**」类型：由机器投放绑定流程触发的投放，其监测链接标记为「机器投放」，便于与手动/批量创建的投放区分对账。
## 6. 执行记录与看板
系统保留**管理看板**，纯读、无写入口，一页：执行记录。异常以执行记录状态与日志呈现，不设独立告警页。
### 6.1 执行记录
展示机器投放的全部编排动作留痕，涵盖测新与跟投两类信号。

| 字段 | 说明 |
|---|---|
| `signal_id` | 信号唯一标识 |
| `signal_type` | 测新 / 跟投 |
| `target_dimension` + `target_id` | 目标（短剧 / 广告计划 / 素材）|
| 自动化任务ID | 绑定到的 Meta / TikTok 任务标识（各平台一条；多部短剧可绑同一任务）|
| 操作人 | 自动触发为「系统」，测新为确认人 |
| 运行 | 自动化任务运行状态（启动 / 暂停）；绑定跳过 / 失败时以文本展示原因 |
| 时间 | 信号接收与绑定时间 |

支持筛选：信号类型 / 维度 / 目标搜索（跨短剧、广告计划、素材等维度）/ 操作人 / 时间范围。

> 测新在测新清单批量发起、弹窗确认，绑定完成后其动作计入本页执行记录；取消不写入。
### 6.2 编排状态模型
一次编排动作从信号接收到绑定自动化任务、再到任务内部跑完，经过**两个环节**。每个环节有独立状态：绑定（机器投放自身 → Meta / TikTok 自动化任务）→ 运行（取自动化任务运行状态）。管理看板仅展示「运行」列，绑定环节不设独立列，绑定跳过 / 失败时并入「运行」列以文本展示原因。

**环节一：绑定（机器投放自身 → Meta / TikTok 自动化任务）**
| 状态值 | 含义 |
|---|---|
| `成功` | 目标已绑定进解析出的 Meta / TikTok 默认任务 |
| `跳过·无默认自动化任务` | 该语言在默认绑定表未配置 |
| `跳过·数据异常` | 信号必填字段缺失 |

**环节二：运行（直接取自动化任务的运行状态）**
| 状态值 | 含义 |
|---|---|
| `启动` | 自动化任务处于启用状态 |
| `暂停` | 自动化任务处于暂停状态 |

> 运行列取值：正常为自动化任务运行状态（启动 / 暂停）；绑定跳过 / 失败时以文本展示原因（无匹配自动化任务 / 跳过·无默认自动化任务 / 跳过·数据异常）。
### 6.3 异常提示
异常（无默认自动化任务 / 决策数据异常 / 绑定连续失败 N 次）以执行记录中的状态与运行日志呈现，不设独立告警页面。素材未就绪不属异常（触发不要求素材就绪，素材由自动化任务扫描获取）。
