## 1. 概述
### 1.1 系统定位
机器投放系统是**触发编排层**：接收触发信号，**把目标（短剧/素材/广告计划）分别绑定进 Meta 与 TikTok 两平台的默认自动化任务**。系统自身不创建广告、不维护账户池、不跨账户复制——这些能力全部由既有**自动化任务执行层**承担。

> 术语说明：本文档「自动化任务」指 **Meta 自动化任务系统 / TikTok 自动化任务系统** 中的既有任务对象，直接承载账户包/预算/竞价等全部执行参数及其绑定短剧；机器投放不复制定义、不维护任务明细，仅引用（绑定）目标任务。

> 术语说明：「默认自动化任务」指机器投放后台维护的绑定配置表：测新按**语种**、跟投按**目标维度 × 语种**（测新按当前操作人逐人维护、跟投归系统）→ 每条各绑一条 **Meta 自动化任务** 与一条 **TikTok 自动化任务**，同一个键可配多条且每条带启用 / 停用状态。信号到达后机器投放按该表取该键下全部启用中的条目解析目标任务并绑定。
### 1.2 核心价值
把两件本由运营/优化师手动做的事，变成自动触发：

1. **新剧测新**：剧上线 / 预上线（信号仅提醒，新剧入测新清单）→ 用户勾选短剧批量发起测新 → 弹窗确认默认自动化任务配置列表并逐部设排期（仅当该剧上游初次投放时间晚于当前东八区时间时默认带出，否则留空）→ 按各短剧语种自动绑定到 Meta / TikTok 测新默认任务并投放，跳转执行记录查看结果。素材不在此环节选定，由自动化任务按「最近上传」扫描获取。
2. **跟投**：smart_ad_put 看数据决策 → 信号入「跟投信号」页 → 用户勾选信号批量确认（弹窗：本批信号清单 + 默认配置列表 + 本批统一排期）→ 按「目标维度 × 语种」绑定进 Meta / TikTok 跟投任务并投放。本期接入，完整需求见 `docs/PRD-机器投放系统-支持跟投信号接入和绑定任务模板多选.md`。
### 1.3 两条路径对比
| 维度 | 新剧测新 | 跟投 |
|---|---|---|
| 触发源 | 短剧上线 / 预上线（信号仅提醒入测新清单），用户批量发起测新 | 智能基建决策 |
| 是否人工确认 | 是（弹窗确认默认配置列表 + 逐部排期）| 是（弹窗确认本批信号 + 默认配置列表 + 本批统一排期）|
| 排期 | 逐部设置，初次投放时间晚于当前东八区时间才默认带出；留空即立即投放 | 本批统一排期；留空即立即投放 |
| 目标粒度 | 短剧 | 短剧 / 广告计划 / 素材 |
| 素材 | 由自动化任务按「最近上传」扫描获取 | 随决策目标 |

> 触发源说明：无法监控到上线 / 预上线事件时，以上线 / 预上线时间作为当日的短剧触发口径。

## 2. 核心概念：触发信号
机器投放系统的唯一输入是触发信号，共两类。
### 2.1 信号公共字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `signal_id` | string | ✅ | 信号唯一标识，幂等键，重复投递不重复绑定 |
| `signal_type` | enum | ✅ | `NEW_DRAMA_ONLINE` / `FOLLOW_UP` |
### 2.2 `NEW_DRAMA_ONLINE`（新剧上线/预上线）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `shortplay_id` | string | ✅ | 上线短剧 ID |
| `shortplay_name` | string | ✅ | 短剧名 |
| `remark` | string | ✅ | 剧本编号（如 `LA001`），与 `shortplay_name` 拼接展示 |
| `language_code` | string | ✅ | 短剧语言，用于默认自动化任务路由 |
| `online_at` | datetime | ✅ | 上线 / 预上线时间 |
| `first_delivered_at` | datetime | 否 | 短剧初次投放时间（由上游带入，不做派生；未投放过为空）。上游即按东八区填写，本系统原值直存、传参前不做任何时区换算 |

> 展示规则：短剧在后台展示时，名称格式为「剧本编号 + 短剧名」，如 `LA001 霸总的替嫁新娘`。业务上短剧分两级——剧本（编号 `LAxxx`）与短剧，后台展示短剧需带上所属剧本编号。

> 信号语义：`NEW_DRAMA_ONLINE` 仅提醒短剧上线 / 预上线、将新剧放入测新清单（带「新上线」标记），**不自动触发测新**；测新由用户从测新清单勾选短剧批量发起（见 §3）。
### 2.3 `FOLLOW_UP`（跟投决策）——即来自智能基建 smart_ad_put 项目
跟投信号本期接入。字段定义、对上游的契约变更与处理流程见 `docs/PRD-机器投放系统-支持跟投信号接入和绑定任务模板多选.md` §2 / §3。
> 跟投的决策统一由 smart_ad_put 产出（含素材级，素材级决策能力由其补齐）。
## 3. 功能一：新剧测新
### 3.1 功能说明
短剧上线 / 预上线后，新剧进入测新清单（`NEW_DRAMA_ONLINE` 信号仅提醒、不自动触发测新）。用户在测新清单勾选要测新的短剧，批量发起测新，弹窗一次性展示**默认自动化任务配置列表**（测新场景按各语种列出的 Meta / TikTok 绑定，仅展示不可修改，本批短剧按各自语种自动解析对应任务）并为每部短剧设**逐部排期**（仅当该剧上游初次投放时间晚于当前东八区时间时默认带出，为空或已过去则留空），确认后按各短剧语种自动绑定到 Meta 与 TikTok 的测新默认任务并投放，全部确认完毕自动跳转执行记录查看绑定结果。素材不在此环节选定，由自动化任务按其素材筛选配置（选用「最近上传的素材」即可）多轮扫描获取新素材。

测新清单页展示全部短剧（新上线短剧带「新上线」标记），列表列为剧本编号 / 剧本名 / 短剧名 / 语言 / 上线时间 / 初次投放时间 / 上线状态（初次投放时间为空显示 `—`），并分页展示（每页 10 / 20 / 50）；勾选短剧后批量「发起测新」。筛选支持语言、短剧名、剧本编号、上线时间范围、初次投放时间范围，各条件之间为「且」关系。短剧名与剧本编号各为独立筛选框，每框支持**单独**（单行输入、整值模糊匹配）与**批量**（多行输入、每行一个值、行内命中任一即通过）两种模式，模式互相独立切换；批量模式只认换行作为分隔符，逗号等按普通字符参与匹配。上线时间范围含首尾，任一端留空即该端不限；初次投放时间范围规则相同，其中初次投放时间为空（显示 `—`）的短剧在设置该筛选任一端时被排除，两端留空则照常展示。剧本编号框严格只匹配编号，剧本名不参与筛选。短剧测新状态二态：未发起 / 已通过；已通过不可重复发起（勾选框禁用），不设驳回。详见变更单 CR-001 / CR-002。
### 3.2 触发规则
- 触发条件：短剧进入「已上线」状态（预上线看预上线时间），不要求素材就绪。
- 触发模式：`NEW_DRAMA_ONLINE` 信号仅提醒（短剧上线 / 预上线后进入测新清单并标记「新上线」），不自动触发测新；测新由用户从测新清单勾选短剧批量发起，无自动分发。
### 3.3 处理流程
```
剧上线 / 预上线（信号仅提醒，新剧入测新清单）→ 用户勾选短剧批量发起测新 → 弹窗确认（展示默认自动化任务配置列表 + 逐部设排期）→ 按语种自动绑定 Meta / TikTok 测新默认任务 → 跳转执行记录查看结果
```
### 3.4 人工确认规则
人工确认是测新流程的最终介入点（前置介入点为测新清单批量发起），以批量级弹窗一次性完成，展示两件事：

1. **默认自动化任务配置列表**：展示测新场景各语种下**启用中**的默认自动化任务绑定（同一语种多条时逐条列出，含未配置，见 §5.1），仅作确认展示、不可在弹窗内修改；本批短剧按各自语种解析该语种下全部启用条目所涉的 Meta / TikTok 测新默认任务（无启用条目的语种确认时跳过并告警）。列表中同时展示每个任务绑定时实际使用的定向包，以及 TikTok 商品数据源开启时的商品匹配方式（见 §5.2），同样仅作核对。
2. **逐部排期**：已选短剧**逐部**给出一个排期输入（东八区）。默认值规则：上游 `first_delivered_at`（初次投放时间）**晚于当前东八区时间**时预填该值；**为空**（未投放过）或**不晚于当前时间**（已早于 / 等于）时留空。留空即立即投放，预上线短剧建议设置。排期只作为参数传给自动化任务、由任务到点执行。

批量发起测新后，弹窗展示默认自动化任务配置列表与逐部排期（已选短剧清单：剧本编号 + 短剧名 + 各自排期），确认动作结果：

- 通过并绑定：本批短剧按各自语种自动绑定进该语种下全部启用条目所涉的 Meta / TikTok 测新默认任务，写入执行记录（操作人 = 确认人）；无启用中默认任务的语种跳过并告警。
- 取消：关闭弹窗，本批短剧保持未发起，可稍后重新发起。

人工不逐个确认预算、竞价等详细参数（由自动化任务承载），不在弹窗内改绑自动化任务（改绑在默认自动化任务页编辑，或删除后重新新增，见 §5.1）。确认完毕后自动跳转执行记录查看绑定结果。排期逐部作为参数传入自动化任务排期字段，由任务到点执行，东八区，未设排期立即执行；上游带入的初次投放时间即东八区，本系统原值直传、不做时区换算。
### 3.5 异常与边界
| 场景 | 处理 |
|---|---|
| 无默认自动化任务（该语言在默认绑定表未配置）| 弹窗列表中该语种行为「未配置」，确认时该短剧跳过并告警 |
| 上游 `first_delivered_at` 为空（未投放过）| 该短剧排期默认留空，等同立即执行；用户仍可逐部自设 |
| 上游 `first_delivered_at` 早于或等于当前东八区时间 | 该短剧排期默认留空，等同立即执行；不预填已过去的时间 |
| 同一 `signal_id` 重复投递 | 幂等去重，不重复提醒 / 不重复入测新清单 |
| 同一短剧重复发起测新 | 已通过不可再次发起（勾选框禁用）|
### 3.6 验收

## 4. 功能二：跟投
> 跟投本期接入。完整需求独立成文：`docs/PRD-机器投放系统-支持跟投信号接入和绑定任务模板多选.md`（信号契约、处理流程、跟投配置、异常与验收）。本节为摘要与指针。
### 4.1 功能说明
smart_ad_put 根据投放数据判定某目标值得继续投放时，信号进入「跟投信号」页待确认；用户在列表中勾选信号批量确认后，系统按各信号的「目标维度 × 语种」解析默认绑定并绑定进 Meta / TikTok 跟投任务。
### 4.2 触发规则
- 触发源：smart_ad_put 决策（`FOLLOW_UP` 信号）。
- 模式：人工批量确认，与测新对称——信号到达只入列表待确认，勾选后批量确认才绑定。
- 目标粒度：短剧 / 广告计划 / 素材。
### 4.3 处理流程
```
FOLLOW_UP 信号到达 → 入「跟投信号」页待确认（不自动绑定）→ 用户勾选信号批量确认（弹窗：本批信号清单 + 配置列表 + 本批统一排期）
→ 按各信号的「目标维度 × 语种」解析「系统」版默认绑定 → 绑定进 Meta / TikTok 跟投自动化任务
```
### 4.4 异常与边界
| 场景 | 处理 |
|---|---|
| 必填字段缺失 / 维度取值非法 | 跳过·数据异常 |
| `language_code` 不在语种对照表内（本系统不支持）| 跳过·无默认自动化任务 |
| 无默认自动化任务（该「目标维度 × 语种」下无启用中的条目）| 跳过·无默认自动化任务 |
| 同 `signal_id` 重复投递 | 幂等去重，不重复入列表 |
| 已绑定的信号再次被确认 | 不可重复确认（勾选框禁用）|
### 4.5 验收
见 `docs/PRD-机器投放系统-支持跟投信号接入和绑定任务模板多选.md` §10。
## 5. 公共规则
### 5.1 默认自动化任务（路由与绑定）
- 后台维护**「默认自动化任务」表**：测新按 场景 × 语种、跟投按 场景 × 目标维度 × 语种；测新按当前操作人逐人维护一版，跟投统一归「系统」一版。跟投的目标维度取信号 `target_dimension`（短剧 / 广告计划 / 素材），同一语种下三个维度各配一组、互不通用（详见 `docs/PRD-机器投放系统-支持跟投信号接入和绑定任务模板多选.md` §3.3 / §4.2）。
- 一条配置 = 键（测新 = 语种；跟投 = 目标维度 × 语种）+ 绑定一条 Meta 自动化任务 + 绑定一条 TikTok 自动化任务 + 状态。下拉数据从各自自动化任务系统拉取，提供搜索/换选。
- **同一个键可配多条，不设上限**：不限制重复新增，新增即追加为一条新条目；每条独立带「启用 / 停用」状态。
- 配置页以**条目列表**展示，顶部按场景分「测新 / 跟投」两个 tab；「新增配置」按钮录入（选语种 + 逐平台绑定，跟投另需选目标维度）；每行三个操作：编辑（键固定，仅调整两个平台的绑定任务）、启用 / 停用、删除（只删这一条）。测新 tab 展示当前操作人已配置的条目；跟投 tab 展示「系统」全局一版、含目标维度列与状态列，仅管理员可用。
- **素材维度的任务候选受限**：跟投在「素材」维度下，绑定任务的下拉只列指定了素材类型的自动化任务；短剧 / 广告计划维度不限。
- **跟投配置无个人之分**：跟投按系统全局一版执行，不区分操作人；后续每个操作人在跟投信号页的确认动作各自留痕。
- 未配置或全部停用的组合不出现在解析结果：测新在批量发起确认时于弹窗配置列表展示为「未配置」，确认时跳过并告警；跟投在批量确认时跳过并提示（弹窗配置列表标「未配置」）。
- 绑定解析：测新在用户批量发起、弹窗确认时按各短剧语种取当前操作人一版中该语种下**全部启用中**的条目（弹窗仅展示配置列表）；跟投在用户批量确认时按各信号的「目标维度 × 语种」取「系统」版中该组合下**全部启用中**的条目绑定，语种取自信号 `language_code` 并经对照表转换。停用的条目不参与解析，也不计为异常。
### 5.2 自动化任务（外部系统）
- 自动化任务 = Meta / TikTok 自动化任务系统中的既有任务对象，机器投放**不复制定义、不维护任务明细**。
- 任务直接承载全部执行参数（账户包/账户数/预算/竞价/优化目标/版位/定向/投放天数/止投）及其绑定短剧，均在任务系统侧管理。
- **定向包**：绑定时取目标任务绑定短剧列表中**第一部短剧的定向包**（Meta / TikTok 各取各的），机器投放不选包、不查定向包列表、不新增定向选择入口。任务模板已按语种区分，首部短剧即该任务语种口径；正常模板保证首部短剧有定向包，缺失按配置异常处理（见 §6.3）。
- **TikTok 商品库**：本期接入。对开启商品数据源的任务，绑定时按「剧本名 + 语种」在该账户商品库内自动匹配商品；未命中时随机兜底——先在同字幕语言商品中随机，没有同语种商品再全库随机。商品库优先取该任务同账户下已配的商品库（沿用任务内已有匹配），任务未配时取该账户下第一个商品库。商品数据源开启时，TikTok 定向按商品级生成（商品字幕语言 + 商品库地区），不再使用首部短剧的定向包。
- 机器投放仅通过「默认自动化任务」表引用（绑定）目标任务，不再维护「模板」「自动化任务配置」等中间层。
### 5.3 与执行层的边界
- 机器投放系统对投放对象的**唯一动作是**：把目标分别绑定进解析出的 Meta / TikTok 默认自动化任务，不新建任务、不触碰任务命名。
- 绑定传入：`target_id` + 排期（`schedule_at`，东八区，可留空即投；测新预上线必选、逐部取值，跟投取本批统一值）+ 默认绑定解析结果（平台 + 任务）+ 各平台 `audience_id`（取目标任务首部短剧的定向包；TikTok 商品数据源开启时该平台不传此值，改由商品级定向生成）。TikTok 商品数据源开启时另传商品绑定：`account_id` + `library_id` + `product_id` + 匹配方式（自动匹配 / 同语种随机 / 全库随机）。测新另传 `shortplay_id`。
- 素材不在测新环节传递：素材由自动化任务按其素材筛选配置（选用「最近上传的素材」即可）多轮扫描获取新素材。
### 5.4 信号通道
- 机器投放系统提供一个信号入口，接收 smart_ad_put 决策与剧上线事件。
- 具体实现（文件/API/MQ）不锁，开发阶段定。
### 5.5 幂等
- 以 `signal_id` 为幂等键，同信号重复投递不重复绑定。
### 5.6 权限
- **测新入口不分发**：所有用户可见相同的测新清单，均可发起测新（当前无按人分配规则；后续如需按人分配，先定义分配规则再补）。
- **操作记录按人可见**：普通用户仅可查看自己的操作记录；管理员可查看所有记录。
- **跟投配置仅管理员**：跟投默认自动化任务为「系统」全局一版，仅管理员可见、可增删改；普通用户在默认自动化任务页看不到跟投 tab。
### 5.7 监测链接
- 监测链接创建类型与「手动 / 批量 / 自动化」区分开，新增「**机器投放**」类型：由机器投放绑定流程触发的投放，其监测链接标记为「机器投放」，便于与手动/批量创建的投放区分对账。
## 6. 执行记录与看板
系统保留**管理看板**，纯读、无写入口。后台共四个外层页：运行看板（仅「执行记录」一页）、测新清单、跟投信号、默认自动化任务。异常以执行记录状态与日志呈现，不设独立告警页。
### 6.1 执行记录
展示机器投放的全部编排动作留痕，涵盖测新与跟投两类信号。

| 字段 | 说明 |
|---|---|
| `signal_id` | 信号唯一标识 |
| `signal_type` | 测新 / 跟投 |
| `target_dimension` + `target_id` | 目标（短剧 / 广告计划 / 素材）|
| 自动化任务ID | 绑定到的 Meta / TikTok 任务标识；同一键下多条启用条目时列出全部，形如 `meta_a、meta_b / tt_a、tt_b`（多部短剧可绑同一任务）|
| 绑定参数 | 本次实际使用的定向包与 TikTok 商品：定向包取自各任务首部短剧；商品数据源开启时展示商品名与匹配方式（自动匹配 / 同语种随机 / 全库随机）|
| 操作人 | 确认人（测新与跟投均为人工作出的确认）|
| 运行 | 自动化任务运行状态（启动 / 暂停）；绑定跳过 / 失败时以文本展示原因 |
| 时间 | 信号接收与绑定时间 |

支持筛选：信号类型 / 维度 / 目标搜索（跨短剧、广告计划、素材等维度）/ 操作人 / 时间范围；分页每页 10 / 20 / 50，点查询或重置后回到第 1 页。执行记录、跟投信号、测新清单三张列表分页形态一致。

> 测新在测新清单批量发起、弹窗确认，绑定完成后其动作计入本页执行记录；取消不写入。跟投在「跟投信号」页勾选信号批量确认，绑定结果同样计入本页；取消不写入。
### 6.2 「跟投信号」页
展示本系统收到的 `FOLLOW_UP` 信号本体（参照上游 smart_ad_put 的「决策日志」页），一份信号一行，不因绑定失败而不记录。执行记录看「绑成了什么」，本页看「收到了什么」——也是跟投的用户入口。
| 列 | 说明 |
|---|---|
| 勾选框 | 仅「待确认」可勾；「已绑定」的禁用。支持表头全选（自动跳过不可勾的行，且只作用于当前页）。勾选跨页保留，翻页不丢已选信号 |
| 接收时间 | 本系统接收该信号的时间 |
| 信号ID | `signal_id` |
| 维度 | 短剧 / 广告计划 / 素材 |
| 目标ID | `target_id` |
| 短剧名 | 按 `script_no` 命中本系统短剧库时展示「剧本编号 + 中文短剧名」；未命中时用上游 `shortplay_name` |
| 语言 / 剧本 | `language_code` + `script_no`，原样展示上游取值，便于发现取值未对齐 |
| 置信度 | 上游 `confidence` 百分数展示；阶段判定可信度，非盈利概率 |
| 原因 | 上游 `reason` |
| 状态 | 待确认 / 已绑定 |
| 详情 | 弹窗展示该信号原始 JSON |

支持筛选：维度 / 语言 / 状态 / 目标搜索 / 接收时间范围；分页与执行记录一致（10 / 20 / 50）。

**批量确认**：列表顶部常驻批量区（已选 N 条 +「批量确认」按钮）。勾选信号后进入确认弹窗，展示本批信号清单 + 本批涉及的「目标维度 × 语种」配置列表（无启用条目的组合标「未配置」）+ 本批统一排期（东八区，留空即立即执行）。确认后各信号按自身「目标维度 × 语种」绑定并写入执行记录（操作人 = 确认人），随后跳转执行记录；无启用条目的信号跳过并提示、保持待确认；取消不写入任何记录。

> 本页只列跟投信号。测新路径由用户从测新清单发起，没有「收到的信号本体」这层。
### 6.3 编排状态模型
一次编排动作从信号接收到绑定自动化任务、再到任务内部跑完，经过**两个环节**。每个环节有独立状态：绑定（机器投放自身 → Meta / TikTok 自动化任务）→ 运行（取自动化任务运行状态）。管理看板仅展示「运行」列，绑定环节不设独立列，绑定跳过 / 失败时并入「运行」列以文本展示原因。

**环节一：绑定（机器投放自身 → Meta / TikTok 自动化任务）**
| 状态值 | 含义 |
|---|---|
| `成功` | 目标已绑定进解析出的 Meta / TikTok 默认任务 |
| `跳过·无默认自动化任务` | 该键在默认绑定表下没有启用中的条目（未配置，或配置全被停用）|
| `跳过·数据异常` | 信号必填字段缺失；任务无已绑短剧或首部短剧无定向包（正常模板不会出现）；账户无可用商品库或商品库为空 |

**环节二：运行（直接取自动化任务的运行状态）**
| 状态值 | 含义 |
|---|---|
| `启动` | 自动化任务处于启用状态 |
| `暂停` | 自动化任务处于暂停状态 |

> 运行列取值：正常为自动化任务运行状态（启动 / 暂停）；绑定跳过 / 失败时以文本展示原因（无匹配自动化任务 / 跳过·无默认自动化任务 / 跳过·数据异常）。
### 6.4 异常提示
异常（无默认自动化任务 / 决策数据异常 / 定向包或商品库缺失 / 绑定连续失败 N 次）以执行记录中的状态与运行日志呈现，不设独立告警页面。素材未就绪不属异常（触发不要求素材就绪，素材由自动化任务扫描获取）。
