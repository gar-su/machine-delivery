# 机器投放系统 · 需求变更单：绑定定向包与 TikTok 商品库
> 变更单 CR-004（2026-10-26）· 目标版本 v1.9 · 影响界面：测新确认弹窗 / 跟投确认弹窗 / 执行记录 / 默认自动化任务页提示 · 对应 PRD §3.4 / §5.2 / §5.3 / §6.1 / §6.3 / §7
## 1. 背景与目标
系统定位是触发编排层，执行参数由自动化任务承载；但绑定时仍有两处参数无可回避：定向包与 TikTok 商品库。此前口径是「由任务承载」，实际任务侧需要绑定时给出具体值，否则新剧无法落位。本次明确两处取值规则，保持编排层不新增选择入口。
| 现状 | 本次变更 |
|---|---|
| 定向包未说明绑定时取值 | 取目标任务绑定短剧列表第一部短剧的定向包，Meta / TikTok 分取 |
| TikTok 商品库未接入 | 本期接入：自动匹配优先，失败随机兜底 |
| 执行记录只列任务 | 增加绑定参数列，展示定向包与商品匹配方式 |
## 2. 变更内容
### 2.1 定向包
- 绑定时取目标任务绑定短剧列表**第一部短剧的定向包**，Meta / TikTok 各取各的。
- 任务模板已按语种区分，首部短剧即该任务语种口径。
- 编排层不选包、不查定向包列表、不新增定向选择入口。
- 正常模板保证首部短剧有定向包；任务无已绑短剧或首部无定向包，按「跳过·数据异常」留痕。
### 2.2 TikTok 商品库
- 仅对开启商品数据源的任务生效。
- 匹配顺序：先按「剧本名 + 语种」在账户商品库内自动匹配；未命中时随机兜底——先在同字幕语言商品中随机，没有同语种商品再全库随机。
- 商品库选择：优先取该任务同账户下已配的商品库（沿用任务内已有匹配），任务未配时取该账户下第一个商品库。
- 商品数据源开启时，TikTok 定向按商品级生成（商品字幕语言 + 商品库地区），不再使用首部短剧的定向包。
- 账户无可用商品库或商品库为空，按「跳过·数据异常」留痕。
### 2.3 绑定传参与留痕
- 传参增加各平台 `audience_id`（TikTok 商品数据源开启时该平台改由商品级定向生成）；TikTok 商品数据源开启时另传 `account_id` / `library_id` / `product_id` / 匹配方式。
- 执行记录增加「绑定参数」列：定向包、商品名与匹配方式（自动匹配 / 同语种随机 / 全库随机）。
- 两个确认弹窗的配置列表同步展示上述信息，仅作核对、不可修改。
## 3. 不在本次范围
- 编排层自选定向包
- 商品库的手工匹配入口（仍在自动化任务侧）
- 商品库为空时的阻断式前置校验（按绑定结果留痕）
- 后端 API 实现
## 4. 验收
- [ ] 绑定时定向包取目标任务首部短剧的定向包，Meta / TikTok 分取
- [ ] 编排层无定向包选择入口，不调用定向包列表接口
- [ ] TikTok 商品数据源开启时先按剧本名 + 语种自动匹配
- [ ] 未命中时先在同字幕语言商品中随机，没有同语种商品再全库随机
- [ ] 商品库优先取任务同账户下已配的库，未配时取账户下第一个
- [ ] 商品数据源开启时 TikTok 定向按商品级生成，不使用首部短剧定向包
- [ ] 执行记录与两个确认弹窗展示定向包 / 商品与匹配方式
- [ ] 定向包或商品库缺失时按「跳过·数据异常」留痕
