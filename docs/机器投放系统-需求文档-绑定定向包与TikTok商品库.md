# 机器投放系统 · 需求文档：绑定定向包与 TikTok 商品库
> 版本 v1.0 · 2026-10-26 · 面向开发与需求评审 · 本文是这两项改动的唯一需求依据；主 PRD、跟投 PRD 及历史变更单中的对应内容仅作历史参考，自本文起不再维护
## 1. 背景与范围
机器投放系统是触发编排层，账户包、预算、竞价等执行参数由 Meta / TikTok 自动化任务承载。但绑定时有两处参数必须由编排层给出，否则新剧无法落位：定向包与 TikTok 商品库。此前口径是「由任务承载」，没有说明绑定时取哪个值；本次把两处取值规则独立定稿。
| # | 改动 | 一句话 |
|---|---|---|
| 1 | 定向包取值 | 绑定时取目标任务绑定短剧列表第一部短剧的定向包 |
| 2 | TikTok 商品库接入 | 先按剧本名 + 语种自动匹配，失败随机兜底 |
本次不改系统定位：编排层仍不选包、不维护商品映射、不新建任务，商品库的手工匹配入口留在自动化任务侧。
## 2. 定向包
### 2.1 取值规则
- 绑定时取目标任务绑定短剧列表**第一部短剧的定向包**，Meta / TikTok 各取各的。
- 任务模板已按语种区分，首部短剧即该任务语种口径，不需要再按语种反查。
- 编排层不选包、不查定向包列表、不新增定向选择入口。
- 绑定传参增加各平台 `audience_id`；TikTok 商品数据源开启时该平台不传此值，改由商品级定向生成（见 §3.3）。
### 2.2 边界
| 场景 | 处理 |
|---|---|
| 任务无已绑短剧 | 跳过·数据异常 |
| 首部短剧在该平台无定向包 | 该平台跳过·数据异常，另一平台照常绑定 |
| 正常模板 | 首部短剧必有定向包；以上两种属配置异常，正常不会出现 |
两个平台独立：一侧跳过不影响另一侧绑定，执行记录分别留痕。
## 3. TikTok 商品库
### 3.1 匹配规则
仅对开启商品数据源的任务生效。绑定每一条「短剧 × 账户」时按以下顺序取商品：
| 顺序 | 规则 | 执行记录展示 |
|---|---|---|
| 1 | 按「剧本名 + 语种」在该账户商品库内自动匹配，命中即用 | 自动匹配 |
| 2 | 未命中，在同字幕语言商品中随机取一个 | 同语种随机 |
| 3 | 没有同语种商品，在商品库全部商品中随机取一个 | 全库随机 |
「剧本名」取短剧所属剧本名；语种取短剧语种。自动匹配为包含匹配、忽略大小写，商品字幕语言需与短剧语种一致。
### 3.2 商品库选择
- 优先取该任务同账户下已配的商品库（沿用任务内已有匹配）。
- 任务未配时，取该账户下第一个商品库。
- 同一账户有多个商品库时，按上述顺序只取一个，不做跨库合并。
### 3.3 商品级定向
商品数据源开启时，TikTok 定向按商品级生成（商品字幕语言 + 商品库地区），不再使用 §2 的首部短剧定向包。因此随机兜底选中的商品会决定该次投放的定向口径，执行记录必须展示商品名与匹配方式，便于运营核对。
### 3.4 边界
| 场景 | 处理 |
|---|---|
| 账户无可用商品库 | 跳过·数据异常 |
| 商品库为空 | 跳过·数据异常 |
| 商品数据源关闭 | 不进行商品匹配，按普通 TikTok 任务处理 |
| Meta 侧 | 不涉及商品库 |
## 4. 绑定传参与留痕
### 4.1 绑定传参
| 参数 | 说明 |
|---|---|
| `target_id` | 目标标识（短剧 / 广告计划 / 素材）|
| `shortplay_id` | 测新路径另传 |
| `schedule_at` | 排期，东八区，可留空即投 |
| `audience_id` | 各平台定向包，取目标任务首部短剧；TikTok 商品数据源开启时不传 |
| `account_id` / `library_id` / `product_id` | TikTok 商品数据源开启时传 |
| 匹配方式 | `自动匹配` / `同语种随机` / `全库随机`，用于执行记录 |
### 4.2 展示
- 测新确认弹窗、跟投确认弹窗的配置列表增加「定向包」「TikTok 商品」两列：定向包取各任务首部短剧；商品列展示匹配规则，仅作核对、不可修改。
- 执行记录增加「绑定参数」列：展示本次实际使用的定向包，以及 TikTok 商品名与匹配方式。
## 5. 验收
- [ ] 绑定时定向包取目标任务首部短剧的定向包，Meta / TikTok 分取
- [ ] 编排层无定向包选择入口，不调用定向包列表接口
- [ ] 任务无已绑短剧或首部短剧无定向包时，该平台按「跳过·数据异常」留痕，另一平台不受影响
- [ ] TikTok 商品数据源开启时先按剧本名 + 语种自动匹配
- [ ] 未命中时先在同字幕语言商品中随机，没有同语种商品再全库随机
- [ ] 商品库优先取任务同账户下已配的库，未配时取账户下第一个
- [ ] 商品数据源开启时 TikTok 定向按商品级生成，不使用首部短剧定向包
- [ ] 两个确认弹窗与执行记录展示定向包 / 商品与匹配方式
- [ ] 账户无可用商品库或商品库为空时按「跳过·数据异常」留痕
- [ ] 商品数据源关闭的任务不触发商品匹配
