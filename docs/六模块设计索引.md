# 机器投放系统 · 六模块设计索引

> 日期：2026-08-11 · 状态：草稿待审 · 关联：《项目整体规划》（M1 机器投放核心 + M0 决策冻结）

## 一、设计总览

六模块设计覆盖机器投放系统执行侧全链路（决策消费 → 执行 → 记录 → 看板），外加 P1 集成与替换节奏。决策端为既有 smart_ad_put（消费指标 → 生命周期判定 → 策略匹配 → 输出决策），本设计全部为执行侧需求。

| 2 | 数据管道契约 | `specs/2026-08-11-data-pipeline-contract-design.md` | Hive 源表 → 结果表契约，供决策端与打分模型 |

## 二、链路视图

```
P1 集成（序6）：素材生产→打分→投放（初始投放）
        │ 素材生产输出含短剧归属（绑定上游保证）
        ▼
投放数据经序2 数据管道回流
        ▼
smart_ad_put（决策端）→ 决策契约（序1）→ 执行端
                                        ├─ 广告平台 autoTask（序4）
                                        ├─ 账户池选取（序3）
                                        ├─ 执行记录（序1）
                                        └─ 看板（序5）
```

**职责边界**：决策端判定（smart_ad_put）与执行端执行（序1-5）分离；P1 三步流水线负责初始投放，机器投放负责跟投，MVP 后并行。

## 三、关键契约（跨序一致）

| 契约 | 定义处 | 消费处 |
|---|---|---|
| 决策对象（decision_id / action / target / strategy / rule_id） | 序1 §2 | 序4（taskName 幂等）、序5（命中统计） |
| rule_id 命中统计 | 序1 契约 | 序5 规则列表（按 rule_id 归并） |
| account_pool / copy_count | 序1 策略 | 序3 选取、序4 跨账户复制 |
| 绑定归属 | 序6 素材生产含短剧归属 | 序1/序4 执行端不绑定 |
| 30min 调度 SLA | 序2 | 序1（决策→执行 ≤30min）、序5（刷新对齐） |

## 四、M0 决策清单（待对齐汇总）

| 模块 | 待对齐项 |
|---|---|
| 序1 执行端 | smart_ad_put 决策输出适配；决策消费通道（文件/API/MQ）；账户池命名规范 |
| 序2 数据管道 | 素材级数据入 Hive 装载链路；ROI 口径统一（决策端 vs 打分模型）；30min SLA 边界；源表命名/分区约定；结果表由谁建 |
| 序3 账户池 | created_by ↔ account_id 映射；池子初始清单；daily_limit 次日重置归属；独立库部署位置 |
| 序4 系统对接 | FB OAuth 授权修复（M0-M1 前置）；渠道优先级（Meta/TikTok 并行 vs 先后） |
| 序5 看板 | 读取接口形态（REST 直查 vs 模块接口）；时间范围筛选粒度 |
| 序6 P1 集成 | 观察期时长与稳定判定阈值；退役决策人归属；三步链路定时频率；打分排序应用规则 |
| 全局 | 规则与阈值归属（打分阈值/跟投规则由运营还是研发维护） |

## 五、MVP 边界（09-30）

- 动作类型仅 `CREATE_DELIVERY`；预算调整 / 关停 / 素材预热不进入契约
- 三步流水线 MVP 后并行，观察期双达标后退役（序6）
- 内网访问、无鉴权（序5）
